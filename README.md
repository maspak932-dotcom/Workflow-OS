# Workflow OS — Premium SaaS Dashboard

A frontend-only dashboard UI inspired by the supplied Workflow OS reference image.

## Stack
- HTML5
- Tailwind CSS via CDN
- Vanilla JavaScript
- Font Awesome icons
- Google Fonts (Inter + Poppins)

## Files
- `index.html` — complete dashboard markup and styling
- `app.js` — interaction/controller logic

## Included interactions
- Responsive fixed sidebar
- Mobile sidebar drawer
- Sidebar active states
- Local Mode ON/OFF toggle
- Privacy toggle
- Hero tab switching
- File picker and drag/drop feedback
- Example chips
- Theme toggle preview
- Toast notifications
- Basic workflow/tool/table button feedback
- "How it Works?" modal
- Ctrl/Cmd + K focuses the task input

## Run
Open `index.html` directly in a modern browser.

For production, replace the demo handlers in `app.js` with your actual workflow/API/file-processing logic.
